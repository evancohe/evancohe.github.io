1. Service Overview

isnote - Island Notes (hereinafter referred to as “isnote” or “Service”) is a mobile application provided by isnote Development Team, designed to help users pin short notes and tags to Dynamic Island via Live Activities, manage an archive of notes, and stay focused with quick reminders.

2. Service Usage

2.1 Service Scope

  • Create, edit, and archive short notes/tags
  • Pin notes to Dynamic Island and Lock Screen via Live Activities
  • Schedule automatic dismiss (for example: 1 hour, tonight, tomorrow morning, custom, or manual)
  • Use quick phrases/templates
  • Support Home Screen / Lock Screen widgets and Control Center controls
  • Support Siri / Shortcuts actions (pin text, pin clipboard, dismiss island note)
  • Export notes as plain text
  • Provide optional iCloud data sync

2.2 Usage Requirements

  • Requires iOS 18.0 or higher
  • Requires a valid Apple ID (for App Store purchase and optional iCloud sync)
  • Requires internet connection (for App Store download and iCloud sync)
  • Dynamic Island features require a compatible device

3. Data Storage and Privacy

3.1 Data Storage

  • All user data is stored only on your device locally (SwiftData)
  • If you enable iCloud, data will sync to your private iCloud account via Apple CloudKit
  • We do not use any servers or cloud storage services of our own
  • We do not collect, transmit, or process any user data

3.2 Data Security

  • Data security is protected by your device security settings
  • iCloud data is protected by Apple’s security measures
  • We cannot access your data

3.3 Data Backup

  • You are responsible for regularly backing up your data
  • We recommend enabling iCloud sync/backup to ensure data security
  • We are not responsible for losses due to device loss, damage, or data loss

isnote - 灵动岛标签（以下简称”isnote”或”服务”）是由isnote开发团队提供的移动应用程序，旨在帮助用户通过实时活动（Live Activities）将短便签/标签固定到灵动岛，管理便签归档，并提供快捷提醒。

2. 服务使用

2.1 服务范围

  • 创建、编辑和管理便签/标签

  • 使用快捷短语/模板
  • 支持主屏幕/锁屏小组件及控制中心控件
  • 支持 Siri / 快捷指令（固定文本、固定剪贴板、下岛）
  • 导出便签为纯文本
  • 提供可选的iCloud数据同步

2.2 使用要求

  • 需要iOS 18.0或更高版本
  • 需要有效的Apple ID（用于App Store购买及可选的iCloud同步）
  • 需要互联网连接（用于App Store下载和iCloud同步）
